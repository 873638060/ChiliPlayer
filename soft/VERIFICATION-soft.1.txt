新椒盐·软解测试分支
基线：系统版 0.3.7.1；分支版本：0.3.7.1-soft.1
包名：car.salt.soft；橙色图标；可与 car.salt.player 同时安装。
最低 Android：6.0 / API 23；包含 armeabi-v7a 与 arm64-v8a。

播放架构
LibVLC Android 3.7.8。当前稳定发布 AAR 的最低 API 为 17，本应用仍限定 API 23。
媒体初始化禁用硬解，随后指定软件解码器白名单：avcodec,araw,flac,vorbis,opus,mpg123,none。
禁用视频、字幕、压缩音频直通及联网自动获取元数据；输出为 PCM -> Android AudioTrack。
没有 Android MediaPlayer 播放回退。APE 也由本地软解库处理；不可定位的文件流仍通过私有缓存兼容读取。
界面、Subsonic、本地文件夹、索引浮窗、曲库缓存、日志沿用 0.3.7.1。
ReplayGain 负增益在播放器音量上衰减，正增益使用 LibVLC 内部 PCM 等化器的平直频段前置增益。不使用系统 LoudnessEnhancer，不修改系统或导航音量。
封面与标签读取目前仍复用 Android 元数据接口；因此“歌曲能软解播放”不保证系统能读取该文件的封面或标签。

并行测试
首次启动需单独授予文件夹访问权限并填写服务器账号；系统版原有数据不受影响。
使用相同文件和服务器对比两版。日志包含引擎版本、软件模块白名单、编码/采样率/声道和实际解码音频块。
无法读取文件时软解同样不能播放；不会把未知失败直接认定为格式问题。
不自动上传日志或连接用户服务器。

构建
在工程根目录运行 soft/build.ps1。soft/libs 包含固定版本库，源码未混入 car/。
系统版仍使用 car/build.ps1。
运行依赖 Android SDK 36 / build-tools 35.0.0、Android Studio JBR；签名沿用本机开发证书，但包名独立。
源码包含 LibVLC Java bindings 源码包、未修改 AAR、许可证和依赖。
LibVLC 原生部分源代码及构建方法：https://code.videolan.org/videolan/libvlcjni
官方制品：https://repo.maven.apache.org/maven2/org/videolan/android/libvlc-all/3.7.8/

限制
本地 ARMv7 Android 6 模拟器测试不等于车机实测；CPU 占用、连续播放温升及音频输出表现仍需实车确认。
验证结果（2026-11-26）
Android 6 / API 23 / ARMv7 模拟器通过：MP3、FLAC、WAV、APE、AAC、ALAC、Vorbis、Opus 实际软件解码；拖动进度、正负 ReplayGain、本地文件与模拟 Subsonic 在线播放、非定位文件流兼容复制、重启恢复、日志导出和原有界面回归。
最终 APK 已安装复验，日志记录实际解码音频块。ARM64 已打包，尚未在 ARM64 设备及 MT3561 实车运行验证。
